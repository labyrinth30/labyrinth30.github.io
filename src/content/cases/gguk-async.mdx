### 문제

GGUK는 Instagram 링크에서 장소를 뽑아 방에 저장합니다. 그 사이에 스크래핑, AI 분석, 지오코딩을 거치는데, 외부 서비스가 느리거나 장소 여러 개 중 일부만 처리되는 경우가 있습니다. 링크를 받았다는 응답을 저장까지 끝났다는 뜻으로 쓰면 사용자가 보는 것과 실제 데이터가 달라집니다.

### 해결 과정

**1. 작업 상태 테이블로 시작**

처음에는 작업 상태 테이블을 두었습니다. 링크를 받으면 작업 행을 만들어 `jobId`를 돌려주고, 클라이언트는 조회 API로 상태와 결과를 받아 가는 구조였습니다. Cloud Tasks는 같은 작업을 두 번 보낼 수 있어서, 워커가 작업을 가져갈 때 만료 시각을 기록하고 늦게 끝난 이전 워커가 최신 결과를 덮어쓰지 못하게 조건을 걸었습니다.

**2. 재시도 기준이 두 곳으로 나뉨**

리뷰에서 팀원이 **실행과 재시도의 기준은 Cloud Tasks에 두고 DB 사용은 줄이자**는 의견을 냈고, 저도 같은 방향으로 고치기로 했습니다. 그런데 상태 테이블이 남아 있는 한, 마지막 시도인지 판단하려면 워커가 큐의 재시도 설정을 직접 조회해야 했습니다. 멈춘 작업을 다시 넣으면 시도 횟수가 처음부터 세어져서 작업별 누적 횟수 상한도 따로 두었습니다. Cloud Tasks가 이미 하는 일을 DB에서 한 번 더 맞추는 코드가 계속 늘었습니다.

**3. 접수만 하는 구조로 전환**

다른 팀원도 상태 컬럼과 멈춘 작업 복구 로직이 필요한지 물었고, 논의 끝에 **상태 테이블, `jobId`, 조회 API를 모두 없앴습니다.** 서버는 방 멤버십과 URL을 확인하고 Cloud Tasks에 등록이 된 다음에만 `202 Accepted`를 돌려줍니다. 중간 상태는 저장하지 않고 최종 결과만 남깁니다. 따로 두려던 워커 서비스도 없애고, 내부 워커는 같은 Cloud Run 서비스에서 OIDC 인증을 거쳐 실행되게 했습니다.

이제 재시도 여부는 워커의 HTTP 응답 코드로만 정해집니다. Cloud Tasks는 5xx와 429만 다시 보내고 나머지 4xx는 버리기 때문에, 응답 코드를 다시 정리했습니다.

- OIDC 검증에 필요한 인증서를 일시적으로 받아오지 못해도 `401`을 주고 있어서 작업이 버려졌습니다. 이 경우는 `503`으로 바꿨습니다.
- AI 응답 형식 오류처럼 재시도해야 하는 `422`도 그대로 두면 버려져서 `503`으로 바꿨습니다.
- Cloud Run 제한 시간(11분)이 Cloud Tasks 응답 기한(9분)보다 길어, 원래 요청이 도는 중에 같은 작업이 한 번 더 실행될 수 있었습니다. 제한 시간을 8.5분으로 줄였습니다.

**4. 일부 실패한 장소만 다시 처리**

상태 테이블이 없어지면서, 장소 하나는 지오코딩에 성공하고 다른 하나는 일시적으로 실패하면 실패한 장소가 기록 없이 사라질 수 있었습니다. 방 핀 저장을 붙일 때 이 부분을 고쳤습니다. 워커는 장소마다 지오코더 1순위 후보를 저장하고, 성공한 장소·출처·핀을 먼저 커밋한 뒤 일시적인 실패가 남아 있으면 `503`을 반환합니다. Cloud Tasks가 다시 보내면 빠진 장소와 핀만 추가됩니다. 같은 작업이 여러 번 들어오므로 장소는 upsert하고, 출처와 핀은 활성 행 유니크 제약으로 충돌을 처리했습니다.

### 코드

핀 INSERT 뒤에 붙는 충돌 처리입니다. 같은 방, 같은 장소에 삭제되지 않은 핀이 이미 있으면 넘어갑니다. 삭제된 핀은 제약 대상이 아니라서 나중에 다시 등록할 수 있습니다.

```typescript
.onConflictDoNothing({
  target: [pins.roomId, pins.placeId],
  where: isNull(pins.deletedAt),
});
```

### 검증 결과

PR #74에서 실제 HTTP 요청과 embedded PostgreSQL로 접수→워커→저장, 부분 실패 후 재시도, 중복 배달, 삭제 후 재등록을 테스트했습니다. 유닛 147건, E2E 28건이 통과했습니다.

운영에서 **링크 접수 응답은 0.2~0.7초**였고, 분석 작업은 성공 73건 기준 **중앙값 6.6초**(p90 13.2초)가 걸렸습니다.
